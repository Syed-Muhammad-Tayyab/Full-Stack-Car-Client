# 🤝 Contributing to Full-Stack Car Client

Thanks for considering a contribution! 🚗💨

1. **Fork** the repo and create a branch: `git checkout -b feature/amazing-feature`
2. Install and run: `npm install` → copy `.env.example` to `.env.local` → `npm start`
3. Make your changes (functional components + hooks, React-Bootstrap for UI).
4. Make sure `npm run build` passes and nothing secret is committed.
5. Commit with a clear message: `feat: add car comparison`
6. Push and open a **Pull Request**.

| Type | Use for |
|------|---------|
| `feat` | a new feature |
| `fix` | a bug fix |
| `style` | CSS / UI-only changes |
| `docs` | documentation |
| `refactor` | cleanup without behavior change |

Be kind and respectful. 💛
